# 2026 Birth Size Reference Charts releases

## 🚀 Release: Updated NICU Birth-Size Reference Charts

### 📄 Overview

This release introduces a new set of birth-size reference charts for NICU populations, recently accepted for publication in ***BMC Pediatrics***. These charts address critical limitations in existing standards and provide a more accurate, clinically representative tool for day-to-day neonatal care.

***

### 📖 Citation

Chou, FS., Yeh, HW., Hsueh, C. et al. Birth-size reference charts for newborns admitted to the neonatal intensive care units. *BMC Pediatr* (2026). https://doi.org/10.1186/s12887-026-06889-1

***

### ✅ Key Improvements

Using data from **1,152,720 infants** admitted to Pediatrix NICUs (2010–2022), this release introduces three major methodological enhancements:

1. **Day-Level Gestational Age Precision**
   * Gestational age recorded **to the day**, eliminating misclassification caused by week-based rounding.

3. **Flexible Curve Fitting**
   * Improved modeling approach captures **true biological variability**, particularly in late preterm and early term infants (35–38 weeks).

4. **Inclusive Dataset**
   * All infants included except statistical outliers.
   * Avoids bias introduced by excluding clinical subgroups (e.g., multiples, infants of diabetic mothers).
   * Ensures charts reflect the **actual NICU population** rather than an idealized subset.

***

### 📈 Additional Features

* Extended gestational age coverage down to **22 0/7 weeks** (earlier than prior charts).
* Updated **BMI reference charts** using the same methodology.

### 🧠 Summary

This release delivers a **more precise, less biased, and more clinically relevant** set of birth-size reference charts—better aligned with the realities of NICU care.
